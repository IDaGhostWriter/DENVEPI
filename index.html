Expected CSV columns
ID unique sample ID; must match tree tip labels
Age years (numeric)
Sex M / F
Locality place name used for grouping
Lat, Long decimal degrees (WGS84)
DENVPCRResult Positive / Negative (also 1/0, POS/NEG, Detected)
Serotype DENV-1…4 (also 1–4, DENV2)
Genotype e.g. GVI, GII, Cosmopolitan
SamplingDate optional; any column whose name contains “date”, “onset”, “collect” or “prelev” (YYYY-MM-DD or DD/MM/YYYY). Needed for the epicurve and time slider.
